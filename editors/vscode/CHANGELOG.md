# Changelog

## 0.1.1

- Extension icon and Marketplace page.
- First release on the VS Code Marketplace.

## 0.1.0

- Syntax highlighting for `.cel` files.
- Error checking on save, with errors and warnings in the Problems panel.
- ▶ Compile button, a "Compile as..." menu for one-off `.sv` / `.v` output,
  and a status bar switch for the output target.
- Settings: `cerilog.target`, `cerilog.outDir`, `cerilog.command`,
  `cerilog.checkOnSave`.
